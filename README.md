## The diagnosis

> Diagnosis: chronic apology reflex — you said sorry to the chatbot, and it logged it as progress.

## How it works

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt` (or the path given by `ENTRY_OUTPUT`, `OUTPUT_DIR`, or
`MAKEFUN_OUTPUT_DIR`).

```sh
python3 main.py
```
